# Saycribe — 产品需求文档 v0.1

> 一句话：按住一个键说话，松开后，整理好的文字出现在光标处。对标 Typeless，先做 macOS。

## 1. 目标用户与场景
- 每天大量打字的人：聊天（微信/飞书/Slack）、写邮件、写文档、给 AI 写提示词。
- 痛点：打字慢；系统自带听写会把"嗯、那个"、说错的话、重复的话原样打出来，还得手动删。

## 2. MVP 范围（v0.1）
| # | 功能 | 说明 | 优先级 |
|---|------|------|-------|
| F1 | 按住说话 | 按住热键（默认 Fn，备选右 Option）录音，松开处理；Esc 取消 | P0 |
| F2 | 免手持模式 | 双击热键锁定录音，再按一次结束 | P1 |
| F3 | 本地识别 | 音频只在本机识别，不上传 | P0 |
| F4 | 口语整理 | 去掉口头禅、重复；处理自我更正（"三点，不对，四点"→"四点"）；补标点、分段、自动排列表 | P0 |
| F5 | 写回任意 App | 写到当前光标处，之后恢复原来的剪贴板 | P0 |
| F6 | 按场景调语气 | 根据前台 App 选风格：聊天口语 / 邮件正式 / 代码与终端（保留英文术语、不加句号）/ 笔记 | P1 |
| F7 | 语音改写 | 有选中文字时说话 = 对选中文字下指令（"改礼貌点"、"翻成英文"），结果替换选区 | P1 |
| F8 | 个人词典 | 人名、术语、品牌的正确写法，送给大模型参考 | P1 |
| F9 | 悬浮提示条 | 屏幕底部居中的小胶囊：听写中（波形）→ 整理中 → 完成 / 出错 | P0 |
| F10 | 历史记录 | 菜单栏里显示最近 20 条，点击可再次复制；同时存原始识别结果 | P1 |
| F11 | 兜底 | 大模型超时（>4 秒）或出错时，直接写入原始识别文字，保证不丢话 | P0 |

暂不做：Windows/手机端、账号与云同步、自动从用户的修改中学词。

## 3. 技术方案
```
热键(CGEventTap) ─▶ 录音(AVAudioEngine, 16kHz 单声道)
                        │ 松开
                        ▼
              本地识别 SenseVoice-Small int8 (sherpa-onnx C API)
                        │ 原始文字（自带标点）
                        ▼
  前台 App + 选中文字(辅助功能 AX) + 个人词典 ─▶ DeepSeek 大模型整理（流式）
                        │ 最终文字
                        ▼
            剪贴板 + 模拟 ⌘V 写入 ─▶ 恢复原剪贴板 ─▶ 存入历史
```

### 模型选择（总指挥评估结论）
- **语音识别：SenseVoice-Small（int8，本地）**
  - 中文、中英混说准确率在同体量模型里最好，自带标点和数字规整。
  - 非自回归结构，在 M2 上识别 10 秒音频只需几十毫秒，比 Whisper 快一个量级。
  - 模型约 230MB，音频不出本机，隐私上和 Typeless 拉开差距。
  - 不足：不支持热词。由大模型那一步结合个人词典来修正。
- **大模型：`deepseek-flash`（V4.1 Flash），关闭思考**
  - 实测：开启思考时首字要多等 3–5 秒，关闭后服务端首字约 0.6–1.3 秒。
  - 整理口语属于"轻改写"，不需要推理。
  - 语音改写（F7）的指令更复杂，可以在设置里切到 `deepseek-v4-pro`（同样关闭思考）。
- **延迟预算**：松开到出字 ≤ 1.5 秒。识别约 0.1 秒，大模型约 1 秒，粘贴约 0.05 秒。

### 外部工具分工
- Grok（本机 CLI）：App 图标、视觉素材。
- Codex（本机 ChatGPT CLI）：代码交叉审查，当第二双眼睛。

## 4. 系统权限
- 麦克风：录音。
- 辅助功能：模拟 ⌘V 写入、读取选中文字。
- 输入监控：全局监听热键。

## 5. 验收标准
1. 在备忘录、微信、浏览器输入框、终端里，按住说话、松开都能写入。
2. 口语整理评测集（`eval/cases.jsonl`）通过率 ≥ 90%：语义不变、口头禅清除、自我更正正确。
3. 断网时仍能写入原始识别文字。
4. 写入后，原剪贴板内容恢复。
