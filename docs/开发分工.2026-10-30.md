# Saycribe 基础功能补齐 · 开发分工（2026-10-30，牙膏哥确认）

## 架构决定
- 识别：留在客户端（本机 SenseVoice）。
- 整理/改写/翻译：全部走牙膏哥的中转（阿里云 ECS 120.24.176.206），客户端不再让用户填 DeepSeek Key；中转后台可换模型。
- 没网就不给用：去掉本机整理兜底（LocalCleaner），断网时 HUD 明确提示"需要联网"。
- 中转部署要求：独立 systemd 服务 + MemoryMax=300M；nginx 新子域名反代，不动现有站点；先独立端口自测；加 1–2GB swap；不影响 motomotos-pay/creem/lyric/nginx。上线后实测内存/CPU 报告。
- 平台：先 Mac + Windows。Windows 在 4060 机器测试（ssh 别名 4060ti，Win10 专业版，administrator）。

## 功能清单（全部要做）
1. 压总延迟：松开到出字 ≤1.5s（短提示词、预连接、中转换快模型）。
2. 新增改口规则（"三点不对四点"→"四点"等）进提示词+评测集。
3. 权限丢失检测、提醒、自动重装热键。
4. 长录音无上限：按停顿（Silero VAD）分段识别+整理再拼接，类似 Claude 语音输入。
5. 从用户修改中自动学词（候选词需确认）。
6. 耳语/小声模式（增益+降噪+开关）。
7. 历史导出、不保存开关、保留天数。
8. 接入中转（替代本地 Key）。
9. 断网不可用提示（不做离线）。
10. App→语气 映射可自定义；修 code 语气与 chat 一样的问题，评测补用例。
11. 多语言（可选 Whisper 类模型）。
12. 首次启动引导。13. 快捷键自定义。14. 自动更新+公证。15. Electron 选区兜底(⌘C)、剪贴板恢复延迟可调。16. Intel/通用包。

## 多端扩展（2026-10-30 17:46 牙膏哥确认）
目标：全部平台做完后同步上线。共用同一个中转（暂用 saycribe-api.motomotos.com，之后牙膏哥会换新域名，客户端要把中转地址做成可配置）和同一套整理规则、改口规则、评测集（eval/cases.jsonl）。

- Bot F「Saycribe·Intel Mac」：x86_64 和通用包（即第 16 项，从 Mac 开发那边接过来）。没有 Intel 实机，用 Rosetta 测 x86_64，并说明这个限制。
