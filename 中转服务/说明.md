# 中转服务（saycribe-relay）源码与部署配置

- `relay.py`：服务端代码，跟 ECS 上 `/opt/saycribe-relay/relay.py` 一致（v1.1）。只用 Python 标准库。提示词从 `../Resources/prompts/` 同步到服务器的 `/opt/saycribe-relay/prompts/`。
- `部署配置/`：systemd 单元、nginx 站点配置、管理脚本 `saycribe-relay-admin`，都是从服务器上拷回来的副本。
- 密钥不在这里：DeepSeek Key 和管理员 token 只放在服务器的 `/etc/saycribe-relay/relay.env`（600 权限）。
- 服务器上的位置：
  - 代码：`/opt/saycribe-relay`
  - token 数据库：`/var/lib/saycribe-relay/tokens.db`
  - 服务：`systemctl status saycribe-relay`
- 签发设备 token：`saycribe-relay-admin issue --user zjh --platform mac --device <名字>`
- 列出设备：`saycribe-relay-admin list zjh`
- 吊销：`saycribe-relay-admin revoke <token_id>`
- 更新代码：先改这里的 `relay.py`，scp 到服务器，`python3 -m py_compile` 检查通过后，再 `systemctl restart saycribe-relay`。
