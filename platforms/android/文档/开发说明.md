# Saycribe 安卓 · 开发说明（2026-10-30）

## 目录
- `app/` 主 App（设置页占位 + `AsrService` 跑在独立 `:asr` 进程，AIDL `IAsrService`）
- `ime/` 输入法服务 `SaycribeImeService`（不依赖 asr-jni，不加载模型，经 Binder 调 :asr）
- `asr-jni/` 包 `com.saycribe.asr`：`saycribe_jni.c` 按 `platforms/core/include/saycribe_asr.h` 封装；Kotlin `Recognizer` / `Segmenter` / `Transcript` / `AsrStatus`
  - `jniLibs/<abi>/libsaycribe_core.so` 存在则链真库，否则自动链 `saycribe_asr_stub.c`（全部返回 MODEL_MISSING）
- `relay/` 中转客户端，默认 `https://saycribe-api.motomotos.com`（`gradle.properties` 的 `saycribe.relayUrl`，运行时可传入覆盖）
- `scripts/build_core_android.sh` 交叉编译 core 为 arm64-v8a / x86_64

## token
`.relay-tokens.env` 已 gitignore，只在运行时从文件/安全存储读取，禁止写进代码和日志。

## 交叉编译前提（当前缺）
NDK、`rustup target add aarch64-linux-android x86_64-linux-android`、`cargo install cargo-ndk`。
sherpa-onnx-sys 2.0.1 在 android 只支持 shared，会下载 `sherpa-onnx-v2.0.1-android.tar.bz2`，需把 `libsherpa-onnx-c-api.so`、`libonnxruntime.so` 一并打包。
