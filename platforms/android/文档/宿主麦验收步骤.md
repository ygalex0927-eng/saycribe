# 宿主麦验收步骤（4060 模拟器 / 真机验收前自测）

> 适用：Typeless → Saycribe Android IME。最终真机验收由牙膏哥对着音箱说话；本文件保证模拟器侧可一次跑完准备与自测。
> 硬规则：不装虚拟声卡、不改 4060 默认音频设备；token 只从文件读、用完删副本、禁止 cat；不改系统 PATH/JAVA_HOME/虚拟化。

## 0. 一键准备

在 4060 PowerShell：

```powershell
# 1) 从 Mac 拷贝 platforms/android/.relay-tokens.env → C:\Users\Administrator\relay.env（不要打开/打印）
# 2) 启动 + 开宿主麦 + 钉死 Saycribe IME + 装 APK + 推 token
cd D:\saycribe-android\源码\platforms\android\scripts
.\host_mic_acceptance.ps1
```

脚本会：

1. 带窗口启动 `saycribe_api34`，参数含 `-allow-host-audio`
2. 开机后执行 `adb emu avd hostmicon`
3. 调用 `pin_saycribe_ime.ps1`：`pm disable-user` Gboard，并 `ime set` 为 Saycribe
4. 安装 `D:\saycribe-android\产物\saycribe-app-debug.apk`
5. 推送 token 到 `files/relay.env` 后**立即删除**主机副本
6. 打开 Notes 并点焦点；打印人工说话清单

仅钉 IME：

```powershell
.\pin_saycribe_ime.ps1
```

## 1. 启动参数（手动等价）

```text
emulator -avd saycribe_api34 -gpu swiftshader_indirect -accel on -no-snapshot-save -no-boot-anim -allow-host-audio
adb wait-for-device
adb emu avd hostmicon
```

说明：模拟器默认关闭宿主麦；`hostmicon` 是开关。`-allow-host-audio` 避免输入被填零。

## 2. 固定 Saycribe 输入法（防 Gboard 抢回）

**只在模拟器内**，不要动产品用户逻辑：

```powershell
adb shell pm disable-user --user 0 com.google.android.inputmethod.latin
adb shell ime enable com.saycribe.android/com.saycribe.ime.SaycribeImeService
adb shell ime set com.saycribe.android/com.saycribe.ime.SaycribeImeService
adb shell settings get secure default_input_method
# 期望：com.saycribe.android/com.saycribe.ime.SaycribeImeService
```

冷启动后再查一次（验收项 ②）：重启 AVD 后再次 `pin_saycribe_ime.ps1`，确认仍为 Saycribe（Gboard 保持 disable-user 状态会跨冷启动保留在该 AVD userdata 内）。

## 3. 要说的句子

```text
今天天气很好，我们一起去公园散步吧
```

- 注入自测：使用已推送的 `files/inject.f32.pcm`（同一句）
- 宿主麦验收：牙膏哥对着「智能音箱 Pro」麦克风说上述句子（不要用同机扬声器 TTS 自听——回声消除会把本机播放消掉）

## 4. 三处验证点

| 场景 | 操作 | 通过标准 |
|---|---|---|
| Notes | `am start …NotesActivity` → 点编辑框 → Hold to talk 说完 | 正文出现整理文；语义正确 |
| Chrome | 打开 Chrome 搜索/地址栏 → Hold to talk | 栏内出现整理文 |
| 短信 | 打开短信草稿 → Hold to talk | 正文出现整理文 |

通过标准（宿主麦）：

- `files/last_ime_mic.txt` 含 `ms=<延迟>` 且 **无** `err=`（或仅成功路径的 `out=` 非空）
- `out` 非空，语义贴近原句（允许标点由中转整理）
- 截图证明上屏

## 5. 错误路径自测（项 ①）

IME 现在**无论成败**都写 `files/last_ime_mic.txt` / `last_ime_inject.txt`：

```text
ms=<毫秒>
err=<错误码>          # 仅失败时
out=<原文或 ERR:…>
```

| 场景 | 做法 | 期望 err |
|---|---|---|
| 断网 | `adb shell cmd connectivity airplane-mode enable` 后 Inject | `需要联网` |
| 空音频 / mic empty | 长按 Hold 但不说话（或宿主麦未开） | `EMPTY` |
| 过短 | 极短按 | `TOO_SHORT` |
| 无注入文件 | 删 `inject.f32.pcm` 后点 Inject | `NO_INJECT_FILE` |

测完恢复网络：`adb shell cmd connectivity airplane-mode disable`

## 7. Token 副本：怎么放、用完怎么删

1. **唯一源文件**：Mac `platforms/android/.relay-tokens.env`（禁止 cat / 写入报告）
2. 拷到 4060：`C:\Users\Administrator\relay.env`（二进制拷贝即可）
3. `host_mic_acceptance.ps1` 会 push → `run-as` 写入 `files/relay.env` → 删 `/data/local/tmp` 与主机副本
4. 收尾再删设备副本：

```powershell
.\host_mic_acceptance.ps1 -StopOnly
# 等价：
# adb shell run-as com.saycribe.android rm -f files/relay.env
# adb emu kill
```

4060 / 模拟器 / box 上不得残留 `.relay-tokens*` / `relay.env`（box 上无关的 `/workspace/relay-token` 不要动）。

## 8. 收尾清单

1. `.\host_mic_acceptance.ps1 -StopOnly`（关模拟器 + 删设备 token）
2. 删临时 pcm / 调试截图 / 同步用 tar（保留 APK、`测试证据`、文档、源码）
3. 若改了 `platforms/android`：先归档 Mac 旧版到 `/Volumes/KINGSTON/项目备份/Saycribe/`，再只同步 android 目录
