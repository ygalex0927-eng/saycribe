### 1.2 Hyper-V 第二代 GNOME 虚拟机

- 目的：真 GNOME（或 KDE）会话测 portal；**WSLg Weston 无 GlobalShortcuts/RemoteDesktop 真授权 UI**。
- ISO：`D:\Saycribe测试\镜像\`（可能是半成品，**先核对大小/校验，不足则续传**）。

### 1.3 传二进制 / 模型 / token（安全）

| 工件 | 建议路径（Linux 侧） | 传法 | 禁止 |
|---|---|---|---|
| `saycribe` release 二进制 | `~/bin/saycribe` 或 `/usr/local/bin/saycribe` | `scp` / U 盘 / 内网 SMB；Mac 仓库 `platforms/linux` 在目标机 `cargo build --release` | 勿把带 token 的环境脚本提交 git |
| 模型 | `~/.local/share/saycribe/models/` | 同步目录：`sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2025-09-09/{model.int8.onnx,tokens.txt}`、`silero_vad.onnx`；或 `saycribe --download-models` | 勿上传到公开盘 |
| **设备 token** | `~/.config/saycribe/token`（0600） | **仅**本机文件或 `printf '%s' "$TOK" \| saycribe --set-token`；TOK 来自已有密钥文件 / 密码管理器 | **不进聊天、截图、工单正文、命令行历史粘贴**；报告里写「已注入」即可 |
| 测试 WAV | 仓库 `测试音频/*.wav` | 随仓库或 U 盘 | — |

```bash
# token：从本机已有文件注入（示例路径，勿把内容 echo 出来）
umask 077
install -d -m 700 ~/.config/saycribe ~/.local/share/saycribe
# 假设密钥已在目标机：~/private/saycribe.token（chmod 600）
saycribe --set-token < ~/private/saycribe.token
saycribe --check          # 期望：连接正常：用户/linux/设备；失败则停
```

环境变量备选（仅当前 shell，勿写进 profile 提交物）：

```bash
export SAYCRIBE_TOKEN="$(cat ~/private/saycribe.token)"   # 仍勿打印
export SAYCRIBE_MODELS_DIR="$HOME/.local/share/saycribe/models"
```

## 2. X11 验收（WSLg）

环境：Ubuntu-24.04 + WSLg；`SAYCRIBE_BACKEND=x11` 或自动检测到 X11。

### 2.1 冒烟

```bash
saycribe --detect          # 期望 X11（或带 xwayland 的 Wayland——若误判，export SAYCRIBE_BACKEND=x11）
saycribe --check
saycribe --app             # 焦点在终端时应含终端 WM_CLASS
```

### 2.2 热键 hold-to-talk

1. 启动：`saycribe`（默热键 `Alt_R`，可在 `~/.config/saycribe/config.json` 改 `hotkey`）。
2. 焦点放在 **xfce4-terminal / gnome-terminal / Windows Terminal 内的 Linux 程序** 文本区。
3. **按住**右 Alt → HUD 进入录音 → **松开** → 识别→整理→粘贴。
4. 通过标准：
   - 按住期间 **只有一次** press/release（不因 autorepeat 多次触发）。
   - 松开后目标框出现整理后文本（语气随 App：终端偏 code，可无句末「。」）。

### 2.3 选区 / 剪贴板恢复 / WM_CLASS

| 步骤 | 操作 | 通过标准 |
|---|---|---|
| WM_CLASS | 焦点切终端 / Chrome，`saycribe --app` | 终端类 vs 浏览器类字符串不同且稳定 |
| 剪贴板恢复 | 先 `saycribe --clip-set 'ORIGINAL-CLIP'`（或手动复制），听写贴屏一次 | 贴完后剪贴板仍为原内容（延迟默认 `clipboard_restore_ms=300`） |
| 选区=改写 | 在可编辑框选中一段字，再 hold-to-talk | 选区被整理结果**替换**（非追加） |
| 无选区=插入 | 取消选区后听写 | 在光标处插入 |

对照本机 Xvfb 自测名目：`terminal received cleaned text`、`clipboard restored`、`fresh PRIMARY → edit`、`stale PRIMARY ignored`。

### 2.4 Chrome / 终端粘贴

- 终端：期望 **Ctrl+Shift+V** 路径；文本进 stdin/缓冲区。
- Chrome（WSLg 内 Linux Chrome 或可聚焦的文本框）：**Ctrl+V**；长文不断字。

### 2.5 Pulse 或真麦 → 识别 → 整理 → 贴屏

**A. 无麦时用 WAV（仍算功能验收，真麦见 §4）：**

```bash
export SAYCRIBE_TEST_WAV=/path/to/测试音频/s2.wav
# 启动 saycribe 后按一次热键（WAV 模式会喂文件）
```

通过：终端/Chrome 出现与 `自测记录/识别准确率.txt` 同级的整理文；中转偶发 offline 时 HUD「需要联网」，可重试一次。

**B. Pulse 环回（WSLg）：**  
`paplay` 测音频 → 默认源录音；或设置 `pavucontrol` 将 monitor 录进 saycribe。通过：与 box 环回同，贴屏有字。

**C. 真麦：** 见 §4。

## 3. Wayland / GNOME 验收（Hyper-V 真会话）

在 **已登录的 GNOME 图形会话** 里开终端（不要只 SSH）。

### 3.1 能力探测

```bash
echo "$XDG_SESSION_TYPE $WAYLAND_DISPLAY $XDG_CURRENT_DESKTOP"
saycribe --wayland-caps
saycribe --portal-caps
```

通过：`RemoteDesktop=true`、`GlobalShortcuts=true`；（GNOME）`Clipboard=true`。若全 false：查 `systemctl --user status xdg-desktop-portal xdg-desktop-portal-gnome`。

### 3.2 首次 portal 授权（点法）

**RemoteDesktop（粘贴必需）：**

```bash
# 可加长超时，方便从容点弹窗
export SAYCRIBE_PORTAL_TIMEOUT_MS=60000
saycribe --portal-rd-test
```

弹窗（GNOME 文案近似「远程桌面 / 控制输入设备 / Share」）：

1. 勾选 **键盘**（Keyboard）；如有「记住 / 恢复 / Persist」一并勾选。  
2. 点 **允许 / Allow / Share**。  
3. 终端应打印 `ok …`；并生成：

```text
~/.local/share/saycribe/rd_restore_token
```

（若设了 `XDG_DATA_HOME` 则在其下 `saycribe/rd_restore_token`。）

**复用：** 再执行一次 `saycribe --portal-rd-test` → **不应再弹窗**（restore_token）。若仍弹：删 token 文件重授一次，或检查桌面「隐私 / 屏幕共享」是否清过授权。

**GlobalShortcuts（hold-to-talk）：**

1. 启动 `saycribe`；首次可能弹出「全局快捷键」授权 / 绑定确认。  
2. 允许后，按配置热键（默认映射 `Alt_R` → portal preferred trigger）。  
3. **按住** = 录音，**松开** = 结束（Activated / Deactivated）。  
4. 若系统设置里可看到 Saycribe 快捷键项，确认未被冲突占用。

### 3.3 粘贴到 GNOME 应用

```bash
# 焦点先点进 gedit / 文本框 / 终端
saycribe --paste 'portal-ok-验收'
```

通过：`method=PortalPaste` 或 `PortalType`（或 Wtype，若会话碰巧是 wlroots）；目标窗口出现文本。  
GNOME **无 wlr-data-control** 时：依赖 xclip(XWayland) 或 portal 键符；`--portal-caps` 后剪贴板链路应仍能贴上。

完整听写：焦点在应用内 hold-to-talk → 松手 → 见整理文。

### 3.4 FIFO 回退验证

1. 在 GNOME 设置中 **撤销** Saycribe 的 GlobalShortcuts 权限（或临时 `SAYCRIBE_PORTAL_TIMEOUT_MS=1` 让 portal 热键失败）。  
2. 再启 `saycribe`：日志/能力应落到 FIFO toggle。  
3. 另开终端：`saycribe --toggle` 一次开始、再一次结束（toggle，非按住）。  
4. 通过：能完成一轮录音→贴屏；无读端时 `--toggle` **迅速失败**（不卡死）。

### 3.5 KDE（时间允许）

```bash
sudo apt install xdg-desktop-portal-kde kwin-wayland   # 或发行版等价包
# 登录 Plasma 会话后：
XDG_CURRENT_DESKTOP=KDE saycribe --portal-caps
# 重复 §3.2–3.4
```

本机箱未装原因：`xdg-desktop-portal-kde` 传递依赖约 **73 包 / ~20MB**（Qt6/KF6），非 curl+dpkg「无痛」；已用 deb 内 `kde.portal` 确认接口含 **GlobalShortcuts、RemoteDesktop**，**无 Clipboard**。真机装上后再测 Clipboard 降级（wl-copy/xclip/portal type）。

## 4. 真麦验收

在 WSLg 或 GNOME VM，**取消** `SAYCRIBE_TEST_WAV`，确认麦克风在系统输入设备中电平跳动。

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 最短说话 | 按住热键，清晰说 ≥ **1 秒** 短句（如「明天开会」）后松开 | 出字；过短无声可不贴（filler-only 不插入） |
| 长录音分段 | 连续说 **>12–20 秒**（含停顿），松手 | 多段 VAD 按 seq 拼成一篇；对照 long.wav 本机 3 段行为 |
| 离线提示 | 断网或改错误 `relay_url` 后听写 | HUD **「需要联网」**；**不**向目标框插入；原始识别可进历史 |
| 鉴权失败 | 错误 token（勿用生产 token 试验） | HUD token/401 提示；不贴屏 |

中转延迟参考（本机热连接）：clean 约 0.9–1.4s；冷 TLS 可能 >1s——验收看正确性优先于绝对延迟。

## 5. 失败排查表

| 现象 | 排查 |
|---|---|
| `--detect` 不符合预期 | `echo $DISPLAY $WAYLAND_DISPLAY`；`SAYCRIBE_BACKEND=x11\|wayland` 强制 |
| `--check` 失败 | token 文件权限 0600；`relay_url`；网络；勿把 token 打进日志 |
| 热键无反应（X11） | 另一程序 Grab；换 `hotkey`；WSLg 焦点是否在 Linux 窗口 |
| 热键无反应（GNOME） | `--portal-caps` 中 GS；设置里快捷键权限；冲突键位；FIFO `--toggle` 兜底 |
| 贴屏无字 | `--paste 'test'`；看 `method=`；终端需 Ctrl+Shift+V；Chrome 焦点在可编辑框 |
| 贴屏后剪贴板被污染 | 查 `clipboard_restore_ms`；是否走了「仅剪贴板」降级（wtype/portal/ydotool 全失败） |
| portal 超时 | 加大 `SAYCRIBE_PORTAL_TIMEOUT_MS`；确认在图形会话点了允许；看 `journalctl --user -u xdg-desktop-portal*` |
| 每次 RD 都弹窗 | 查 `~/.local/share/saycribe/rd_restore_token` 是否写出；桌面是否禁止持久授权 |
| 误入「改写」 | Wayland 只信 PRIMARY；勿把 CLIPBOARD 当选区；取消文本选区再测插入 |
| ASR 差 / 空 | 模型路径与 sha；`SAYCRIBE_MODELS_DIR`；麦采样率；对照 `测试音频` CER |
| clean 报离线 | 重试；热 ping；海外冷启动慢——非必失败 |
| WSL 无 GUI | `wsl --update` 未成；Win10 需 Store WSL；重启 |
| ISO 损坏 | `D:\Saycribe测试\镜像\` 续传并校验 SHA256 |
